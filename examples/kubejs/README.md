# Path of Ascension — Minecraft 1.21.1

Скопируйте `server_scripts/main.js` в `kubejs/server_scripts/main.js` вашей сборки,
заменив предыдущий генератор этого дерева. Не запускайте оба генератора одновременно.
Также скопируйте папку `assets` в `kubejs/assets`: она содержит иконку дерева.
Нужны Passive Skill Tree и KubeJS. Скрипт и ресурсы не включаются в JAR мода автоматически.

После первого запуска скрипта перезапустите игру: `JsonIO.write` создаёт файлы
в `kubejs/data`, но не обновляет уже загруженный набор ресурсов. В локальном
`run/kubejs` проекта файлы уже подготовлены.

Дерево `skilltree:main_tree` содержит 21 навык: маг, воин, инженер — по 7 узлов.
Тег `class` позволяет выбрать один стартовый класс. Каждая ветка имеет два пути
по три узла; её два финальных навыка взаимоисключающие. Базовые деревья
alchemist, cook, hunter и tree перекрываются пустыми списками.

- Маг с Iron's Spellbooks: сила заклинаний, максимальная мана, восстановление маны.
  Старт даёт +10% к каждому и -10% к здоровью, урону атак и броне.
  Это снижение количества брони, а не отдельного показателя её эффективности.
- Маг без этих атрибутов: опыт с мобов и шанс бесплатного зачарования, без штрафов старта.
  После установки Iron's Spellbooks снова дайте скрипту сгенерировать данные и перезапустите игру.
- Воин: урон/скорость атак либо здоровье/защита; финалы — Berserker и Bulwark.
- Инженер: скорость добычи либо экономия прочности добывающих инструментов
  и дальность взаимодействия с блоками; автоматизации машин эта ветка не добавляет.

Процентные бонусы атрибутов используют operation=1 (доля базового значения),
плоские — operation=0. ID модификаторов стабильны, в формате ResourceLocation.
Подсказки формируются модом из фактических бонусов. UUID из старого примера не нужны.

Проверяйте изменённый баланс на тестовом персонаже. Скрипт не сбрасывает ранее
изученные навыки; при переходе со старого дерева или смене режима мага сначала
сбросьте изученные навыки штатными средствами мода.
